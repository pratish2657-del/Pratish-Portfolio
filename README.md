# Pratish — VFX Cinematic Portfolio

## Run

```powershell
npm install
npm run dev
```

Then open `http://localhost:5173/`.

## Features

- Cinematic dark visual system
- Three.js particle globe
- Cursor-reactive particles
- 3D orbit rings
- Cinematic portrait treatment
- Smooth Lenis scrolling
- Scroll-triggered reveals
- 12-second hero auto-transition
- EduSphere live CTA
- Instagram / GitHub / LinkedIn links
- Responsive mobile layout
- Reduced-motion support

The portrait asset is included in `src/assets/pratish-cutout.png`.
