⚙️ Running Locally

Clone the repository:

git clone https://github.com/pratish2657-del/Pratish-Portfolio.git

Enter the project:

cd Pratish-Portfolio

Install dependencies:

npm install

Start the development server:

npm run dev

Create a production build:

npm run build

Preview the production build:

npm run preview
